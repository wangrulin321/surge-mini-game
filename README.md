# 球潮 SURGE

一个无需构建工具的 Canvas 生存小游戏第一版原型。

## 运行

直接双击 `index.html` 即可运行。也可以在当前目录启动任意静态服务器后访问页面，例如：

```powershell
python -m http.server 4173
```

## 操作

- 电脑：`WASD` 或方向键移动。
- 手机：在竞技场内拖动，白色玩家核心会朝手指方向移动。
- 道具：碰到后立即触发。

## 当前道具

- 冲刺：5 秒内移动速度提升。
- 冰冻：球潮减速 4 秒。
- 震荡波：推开玩家附近的追兵。
- 脉冲清扫：清除小球，保留已经长大的球。
- 追踪弹：自动锁定并击破最近的敌人。
- 环刃：击破玩家附近的敌人。
- 连锁电弧：最多跳跃攻击 3 个敌人。
- 爆破弹：锁定最近敌人并对周围造成范围爆破。
- 穿透射线：沿目标方向贯穿一条直线，最多击破 5 个敌人。
- 毒雾尾迹：4 秒内在身后留下短暂毒雾，敌人碰到即死亡。
- 护盾：6 秒内持续无敌。
- 护卫环：永久生成 3 个旋转防御球，每击败 1 个敌人就消耗 1 个护卫球。
- 增殖：负面道具，让新球更快出现。

效果球不会固定在原地，它们会缓慢随机移动，碰到竞技场边缘后反弹。

大球会比普通小球更快。大球被毒雾、脉冲清扫或护卫环击破时，会根据内部质量爆出 2 至 7 个碎球，数量有上限，不会一次填满场地。
